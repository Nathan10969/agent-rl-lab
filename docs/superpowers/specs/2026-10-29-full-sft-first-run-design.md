# Blocksworld 全量 SFT 首次运行设计

## 目标和范围

从本地 Qwen2.5-0.5B-Instruct 原模型出发，使用 Blocksworld v1 训练集的全部 3021 道题运行一次 1 epoch 的 LoRA SFT，记录验证表现，作为学习和后续实验的起点。不续用试运行 adapter，也不读取 test、6–7 块泛化集或 PlanBench 进行调参。

## 训练设置

- 模型、tokenizer 和 prompt/mask 复用现有 `sft/` 实现；核验本地权重和数据指纹。
- 采用试运行的 LoRA：rank 16、alpha 32、dropout 0.05，目标为 q/k/v/o 和 gate/up/down 投影；AdamW 学习率 2e-4、weight decay 0、seed 0、float32。
- batch size 8，固定 padding 至 320，复用已试运行的 MPS 缓存清理方式；最后一批 5 条不得丢弃，共 378 个优化步。当前全量 train/val 均最长 315 token；未来超长样本须报错，不静默截断。
- 第 126、252、378 步用完整 378 条 val 计算 token 加权 loss，保存独立 checkpoint；按验证 loss 最低的 checkpoint 选择最终 adapter，记录各 checkpoint 和选择规则。不声称该指标保证规划成功率最高。
- 相同贪心生成设置下，用完整 378 条 val 对原模型和选中 adapter 分别执行模拟器判分；区分格式正确、动作合法、目标成功。生成用较小 batch 控制内存，保留生成限制并记录配置。

## 安全和可追溯性

- 新增独立入口，保持已提交的试运行代码及成果不变；每次运行使用新建的唯一输出目录，发现目录已存在时拒绝覆盖。
- 逐步记录训练 loss、验证 loss、内存观察和配置，保存数据、模型与代码版本信息；分离原始模型与 adapter。不将 MPS 采样当作完整内存峰值或系统 swap。
- checkpoint 至少保存 adapter 和训练进度；若不能保存优化器与随机状态，不称为可精确恢复训练。结束前先保存，再进行较长的生成评测，以防评测意外失败导致全部训练成果丢失。
- 先进行不覆盖文件的自动测试与最小烟雾测试，确认输出安全、尾批与 mask，然后在用户明确选择的本机执行一次完整训练。估算时长仅作参考，不保证 20 分钟完成。
