# ALFWorld 动作格式对照设计

目标：在上一轮的三道不同类型开发题上，检查提供静态命令格式后模型的行为与任务成功情况。仅供小样本诊断，不作为 benchmark 成绩或训练收益。

- 对照组使用已有 `pilot-02` 的三条结果；实验组逐项核验任务 ID 和原始配置后运行同样三题，环境固定 `valid_seen`、随机种子 0、不做领域随机化。
- 同一个 Qwen3.8-27B-FP8 模型和推理后端；temperature 0、关闭 thinking、最多 48 token、换行停止、上下文上限 4096，每题最多 20 步。
- 在首次用户消息中新增一份静态、任务无关的 ALFWorld 命令格式，依据已安装 TextWorld 版本的 `help` 语法；不提供按当前状态筛选的动作、目标解法或轨迹示范。
- 记录提示版本及摘要；每道题保留新的私有轨迹并对照旧结果，报告成功数、动作及反馈的变化；不使用最终测试集，不训练、不调奖励。
- 默认不带格式说明时必须保留原来的消息文本和评测行为；路径、日志、模型、数据和原始轨迹不推送公开仓库。

局限：题目只有三道；原始记录没有保存初始观察的哈希，只能核对相同题目、固定随机种子、配置和环境文件，不能补证原始观察逐字相同。
