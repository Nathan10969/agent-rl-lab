# 真实 Qwen 的逐步价值头：一次链路冒烟

## 目的和边界

把多轮策略采样时保存的前文 token 接到独立价值头，验证三个动作之前各有一个预测值；这不是训练效果实验。保持基础多轮 GRPO 的整局奖励、策略 loss 和评测不变，优势仅做诊断，没有用于更新策略。

策略是本地 Qwen2.5-0.5B-Instruct 加多轮 SFT adapter；通过对照轨迹原配置中模型及 adapter 文件的 SHA-256，确认与第一批采样时使用的资产一致。复用一条已有训练轨迹，不重新生成；初始随机种子为 20261113。

## 轨迹、奖励与观测

这条轨迹有三步，依次是非法动作、纠正动作、完成目标；三个前文补齐后分别为 256、256、384 token。按非法 −0.1、合法 0、目标完成 +1 和 gamma 0.9，逐步奖励为 `[-0.1, 0, 1]`，reward-to-go 为 `[0.71, 0.90, 1.00]`。

Qwen 每一步的最后层前文表示为 896 维；价值头是 896 到 1 的线性层，共 897 个参数。下列值是未训练随机价值头的本次输出，不是任务成功率：

| 步数 | 初始价值预测 | 对应回报 | 回报减预测 |
|---|---:|---:|---:|
| 0 | −12.8655 | 0.71 | +13.5755 |
| 1 | −12.0504 | 0.90 | +12.9504 |
| 2 | −11.7096 | 1.00 | +12.7096 |

只对这三个固定表示进行一次价值头 SGD 更新（学习率 `1e-4`，梯度裁剪阈值 1），价值均方误差从约 171.1803 变为 170.4075；裁剪前梯度范数约 7737.31。这个下降只说明这一批的单次更新改变了参数，不证明价值头学会预测或策略变好。随机头的尺度过大，不能直接把上述优势送入策略训练；下一步需先在多条训练轨迹上检查初始化、损失和价值预测的稳定性。

价值损失没有向策略模型传播梯度；策略参数对象及 PyTorch 版本计数未变化。价值头写入临时检查点并重新加载，在缓存的同一批表示上预测的最大绝对差为 0；临时文件已自动清理，没有保存可续训的价值头。MPS driver 阶段采样最高约 2.667 GiB，swap 变化 0；阶段采样不能保证瞬时峰值没有更高。

## 测试与限制

CPU 随机迷你 Qwen + LoRA 测试检查：左补齐与无补齐结果一致、动作后的 token 不进入当前价值输入、异常 mask 被拒绝、价值头反传不触及策略、权重保存加载一致，以及逐步优势的维度和梯度隔离。联合相关环境与 GRPO 测试为 56 项通过、10 个 subtest 通过。

本次无价值网络的独立验证、无真实策略更新、无成功率对照，也不能判断更细奖励有没有改善任务表现；不能将此称为完成多轮 actor–critic 训练。当前每条轨迹使用的有限回报只覆盖已记录的步数，截断后的未来未补价值。
