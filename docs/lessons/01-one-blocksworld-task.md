# 第一小步：看懂一条积木任务

目的：先知道模型输入什么、要输出什么、程序凭什么判对。此页只是手工例子，模拟器尚未实现。

## 场景

桌上有两块积木 A 和 B，两块上面都没有其他积木。机械手为空，并且一次只能拿一块。

目标：让 A 放在 B 上。

## 一份可行的答案

```text
pickup(A)
stack(A, B)
```

- `pickup(A)`：从桌上拿起 A。需要手为空，A 在桌上，且 A 上没有积木。执行后，手拿着 A。
- `stack(A, B)`：把手中的 A 放到 B 上。需要手确实拿着 A，而且 B 上没有积木。执行后，A 在 B 上，手为空。

这里不要求参考答案文本一模一样；只要计划的每一步合法，且最终满足规定目标，就可按成功评分。暂不奖励最短计划。

## 两种错误要分清

```text
stack(A, B)
```

手还没拿起 A，不能直接堆叠：动作非法。

```text
pickup(B)
stack(B, A)
```

两步可以合法执行，但最后是 B 在 A 上，不满足目标。

## 这条任务怎样连接训练

- SFT：把正确计划作为 assistant 回答，让模型学习如何生成。
- GRPO / DAPO：让模型生成多份候选计划，模拟器逐步执行并给奖励。
- 多轮 agent：模型先生成第一步，收到环境执行结果后，再生成下一步。
- 记忆：等任务确实存在信息遗漏或跨步依赖时，再加入记忆动作，而不是给这个两步小题强行加记忆。
