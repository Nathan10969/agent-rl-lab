# 0.5B 阶段归档与 27B 迁移准备

## 这一阶段完成了什么

在 Qwen2.5-0.5B-Instruct 和积木世界上，我们依次练习了 LoRA SFT、GRPO 和 DAPO 的教学实现、多轮交互、逐步奖励、reward-to-go、价值预测与每步优势。各实验的实现范围和评测限制见[学习记录 2–24](../../README.md#从这里开始)。这不是在真实机器人上训练，也不声称完整复现相关论文。

最近一次三种子对照中，有价值头和无价值头的策略在相同 20 道开发题上的成功集合相同；结果仅适用于本次起点、任务、参数及训练预算，不说明价值头普遍无效。后续固定状态检查发现，在检查的 40 段历史中，旧动作的指定 token 序列概率多数变化较小；这不代表完整策略分布一定没有变化。详见[三种子对照](23-paired-value-three-seeds.md)和[固定状态检查](24-fixed-state-policy-probabilities.md)。

0.5B 阶段的项目副本、已有数据、未提交代码和实验输出已单独复制到本机归档；原目录保留。文件内容经过复制后核对，Git 历史另有本地 bundle。**同机副本不能替代异地备份。** 模型、数据、原始轨迹和历史备份均不上传公开仓库；部分多轮代码与测试尚未公开，当前公开记录不足以独立重放所有实验。

## 下一阶段要回答的问题

从头评估 27B 模型，不能直接加载 0.5B 的 LoRA、价值头或优化器，也不把 0.5B 的分数当作新模型的成绩。积木环境保留作流程检查及对照；[ALFWorld 文字环境](https://github.com/alfworld/alfworld)是下一步多轮交互候选，不代表真实机械臂控制。

计划先测试官方 [Qwen3.8-27B-FP8](https://huggingface.co/Qwen/Qwen3.8-27B-FP8) 在单张 A800 上的加载和生成。FP8 是 8 位浮点权重，不等同于 INT8。先用少量固定开发题检查格式、合法性、任务成功、耗时和显存；先不训练，也不使用最终测试集选模型。模型身份、具体修订、环境版本和生成设置需要记录。若未来比较强化学习方法，还需检查随机采样时奖励是否存在组内差异。

截至本记录：模型配置文件已核对，完整权重和推理环境仍在准备；**尚未完成 27B 加载、积木或 ALFWorld 评测，也没有 27B 的显存或成功率结论**。推理可用不等于 LoRA 反向传播或多轮 RL 已可用；后续训练兼容性应单独验证。
